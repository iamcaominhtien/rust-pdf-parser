# Fonts of the friendly mode

Embedded in friendly-mode pages (base64 `@font-face`) unless `--fonts system` is given.
All are licensed under the SIL Open Font License 1.1 (see the `OFL-*.txt` files); none
declares a Reserved Font Name, so the subsets below keep their family names.

| File | Font | Subset |
| --- | --- | --- |
| `literata-roman.woff2`, `literata-italic.woff2` | Literata (The Literata Project Authors), variable weight 380–700, optical size pinned at 12 | Latin, Latin Extended, combining marks, Greek, Vietnamese, punctuation, super/subscripts, arrows, ligatures |
| `plex-sans.woff2` | IBM Plex Sans (IBM Corp.), variable weight 400–600 | as above |
| `plex-mono-400.woff2`, `plex-mono-600.woff2`, `plex-mono-400-italic.woff2` | IBM Plex Mono (IBM Corp.) | Latin (from Fontsource); embedded only when a paper contains code |
